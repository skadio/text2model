Changelog
=========

All notable changes to this project are documented in this file.

[1.1.0] - 2026-07-15
---------------------
- Added `text2model --editor`, a GUI dataset editor (Flet) for browsing,
  editing, and running Text2Zinc problems, with an AI chat assistant.
  Included in the base `text2model` install.
- Added `--dataset-path` to `text2model` and `evals/evaluate.py` to
  generate/benchmark against a local Text2Zinc CSV (e.g. one saved from the
  editor) instead of the default skadio/text2zinc HuggingFace dataset.
- Added `utils.load_text2zinc_dataset()`, a shared HF-or-local dataset loader.

[1.0.0] - 2026-07-09
---------------------
- First stable release.
- Cleaned up duplicate files that existed both at the repo root and under
  text2model/ (grammar.mzn, knowledge_graphs/, prompts/, utils.py, main.py).
  The text2model/ package directory is now the single source of truth for
  both package data and the CLI entry point; the root-level main.py shim
  has been removed in favor of the `text2model` console script.
- Fixed generate_knowledge_graph.py to import from the text2model package
  instead of the removed root-level utils.py.
- Switched project license from MIT to Apache License 2.0.
- Added LICENSE and this CHANGELOG.txt.

[0.1.0] - Pre-1.0.0 history
----------------------------
- Refactored the project into a pip-installable package (text2model/) with a
  `text2model` console script entry point.
- Added copilot strategies: baseline, cot, knowledge_graph,
  cot_with_code_validation, cot_with_grammar_validation,
  cot_with_code_and_grammar_validation, agents, agents_with_code_validation,
  and gala (global agents).
- Added evaluate.py for scoring generated MiniZinc models and
  generate_knowledge_graph.py for producing knowledge graphs used by the
  knowledge_graph strategy.
- Added GitHub Pages site (index.html) and online leaderboard integration.
- Added GitHub Actions test workflow and pytest-based unit/integration tests.
