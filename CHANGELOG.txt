Changelog
=========

All notable changes to this project are documented in this file.

[1.3.6] - 2026-08-05
- Updated default model settings and editor GUI buttons

[1.3.5] - 2026-08-03
- Added an "Upgrade Dataset" button to the editor GUI, visible in HF Space mode
  too, that force-downloads the latest `skadio/text2zinc` from HuggingFace,
  bypassing the local `datasets` cache

[1.3.4] - 2026-08-03
- Renamed `--dataset-path` to `--text2zinc-path` (`text2model` and `evals/evaluate.py`)
- Added `--upgrade-text2zinc` to force a fresh download instead of reusing the HF cache
- Warn (or error, with `--upgrade-text2zinc`) if no HF token is set, since
  `skadio/text2zinc` is gated and silently falls back to stale cache otherwise

[1.3.3] - 2026-07-27
- Documented the `--reasoning-effort` hint in the README
- Removed stray `--all-sources` flag; fixed no-args help printing

[1.3.2] - 2026-07-26
- Added copy-CSV-to-clipboard button for HF Spaces (file downloads are blocked there)

[1.3.0] - 2026-07-24 (in progress)
- Added local Hugging Face / unsloth model support (`text2model/huggingface.py`), including
  gpt-oss-20B, Qwen3-0.6B, Llama-3.2-1B/3B, and Gemma-2-9B fine-tuned checkpoints; installable
  via the new `text2model[gpu]` extra
- Refactored copilot strategies out of main.py into one module per strategy under
  `text2model/copilots/`
- `knowledge_graph` strategy now generates a `.ttl` on the fly if none is pre-built for the
  problem, instead of requiring one
- Renamed `--include-unverified` to `--full-dataset`
- `--problem-ids` now accepts problem identifiers (e.g. `nlp4lp_58`) in addition to indices
- Added `--list-problem-ids` and `--reasoning-effort` flags
- Added gpt-5.5 / gpt-5.6 model support
- Added "New Problem" creation and field validation to the dataset editor; editor chat
  assistant model is now configurable

[1.2.0] - 2026-07-20
- Several cosmetics and UI updates
- Fix screen size wxh
- Fix Left and Right hand side to save space

[1.1.1] - 2026-07-19
- Added --list-strategies flag
- Fixed a printout bug when running without arguments
- Fixed duplicate model printing
- Print statements now append "%" so that they are treated as comments when redirecting output to a minizinc file

[1.1.0] - 2026-07-15
---------------------
- Added `text2model --editor`, a GUI dataset editor (Flet) for browsing,
  editing, and running Text2Zinc problems, with an AI chat assistant.
  Included in the base `text2model` install.
- Added `--dataset-path` to `text2model` and `evals/evaluate.py` to
  generate/benchmark against a local Text2Zinc CSV (e.g. one saved from the
  editor) instead of the default skadio/text2zinc HuggingFace dataset.
- Added `utils.load_text2zinc_dataset()`, a shared HF-or-local dataset loader.

[1.0.0] - 2026-07-09
---------------------
- First stable release.
- Cleaned up duplicate files that existed both at the repo root and under
  text2model/ (grammar.mzn, knowledge_graphs/, prompts/, utils.py, main.py).
  The text2model/ package directory is now the single source of truth for
  both package data and the CLI entry point; the root-level main.py shim
  has been removed in favor of the `text2model` console script.
- Fixed generate_knowledge_graph.py to import from the text2model package
  instead of the removed root-level utils.py.
- Switched project license from MIT to Apache License 2.0.
- Added LICENSE and this CHANGELOG.txt.

[0.1.0] - Pre-1.0.0 history
----------------------------
- Refactored the project into a pip-installable package (text2model/) with a
  `text2model` console script entry point.
- Added copilot strategies: baseline, cot, knowledge_graph,
  cot_with_code_validation, cot_with_grammar_validation,
  cot_with_code_and_grammar_validation, agents, agents_with_code_validation,
  and gala (global agents).
- Added evaluate.py for scoring generated MiniZinc models and
  generate_knowledge_graph.py for producing knowledge graphs used by the
  knowledge_graph strategy.
- Added GitHub Pages site (index.html) and online leaderboard integration.
- Added GitHub Actions test workflow and pytest-based unit/integration tests.
